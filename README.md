# Ghayoomi Examer

> ربات تلگرامی تمرین و آزمون زبان انگلیسی، ویژهٔ دانش‌آموزان پایه‌های دهم تا دوازدهم.

**Ghayoomi Examer** با تمرکز بر محتوای کتاب‌های **ویژن ۱، ۲ و ۳** طراحی شده است تا مرور واژگان، انجام آزمون و مشاهدهٔ رتبه، همگی در یک ربات تلگرامی در دسترس باشند.

## قابلیت‌ها

| قابلیت | کاربرد |
| --- | --- |
| 🃏 فلش‌کارت | مرور و تمرین واژگان در قالب کارت‌های آموزشی |
| 🧪 آزمون‌ساز | آماده‌سازی آزمون برای تمرین و سنجش آموخته‌ها |
| 🏆 جدول رتبه‌بندی | نمایش رتبهٔ کاربران و ایجاد انگیزه برای ادامهٔ یادگیری |
| 🛠 پنل مدیریت | مدیریت محتوای آموزشی و امکانات مدیریتی ربات |

## فناوری‌ها

- **Python 3.11** — توسعهٔ برنامه
- **aiogram 3** — ارتباط با تلگرام و مدیریت تعاملات ربات
- **SQLite** — نگهداری داده‌ها
- **GitHub Actions** — اجرای دوره‌ای، پایش وضعیت و ابزارهای مدیریت داده

## اجرا و نگهداری

فرایندهای عملیاتی پروژه در GitHub Actions تعریف شده‌اند:

- اجرای دوره‌ای ربات، با امکان اجرای دستی؛
- بررسی وضعیت و درخواست راه‌اندازی مجدد در صورت نبودِ اجرای فعال یا در صف؛
- ذخیره و بازیابی دیتابیس بین اجراها برای حفظ داده‌ها.

زمان دقیق شروع اجراها به زمان‌بندی GitHub Actions وابسته است و اجرای بدون وقفه تضمین نمی‌شود.

## دسترسی به سورس و محرمانگی

این مخزن برای **معرفی عمومی پروژه** نگهداری می‌شود. سورس برنامه در فایل `src.enc` به‌صورت رمزگذاری‌شده قرار دارد؛ بنابراین بررسی یا اجرای مستقل کد از فایل‌های عمومی این مخزن امکان‌پذیر نیست.

در اجرای خودکار، مقادیر حساس از **GitHub Secrets** خوانده می‌شوند. فایل `.env.example` صرفاً الگوی تنظیمات است؛ توکن، رمز عبور، کلید رمزگشایی و اطلاعات واقعی کاربران نباید در فایل‌های عمومی یا مستندات پروژه منتشر شوند.
