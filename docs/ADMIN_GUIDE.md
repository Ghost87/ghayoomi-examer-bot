# 🛠 راهنمای پنل مدیریت Ghayoomi Examer

> برای صاحب ربات و ادمین‌ها 👑🛡

---

## 🔓 ورود به پنل (مخفی توسط یوزرنیم/رمز)

پنل مدیریت **توی منو و هیچ دگمه‌ای نیست** — فقط خودت می‌دونی کجاست:

1. دستور `/admin` را **خودت** در چت ربات تایپ کن
2. ربات **نام کاربری** و **رمز** را می‌پرسد — همان‌هایی که خودت در `.env` گذاشتی (`ADMIN_LOGIN` / `ADMIN_PASSWORD`)
3. درست باشی، وارد اتاق فرمان می‌شی 👑

> 💡 این یوزرنیم/رمز را **به هیچ‌کس نده** و فقط در `.env` خودت نگه دار — هر وقت خواستی عوضشان کن.

صفحهٔ اول پنل، آمار زنده می‌دهد: کاربران، فعال ۲۴ساعت/هفته، کارت‌ها، آزمون‌ها و نتایج منتظر تأیید.

---

## 🧪 ساخت آزمون

دگمهٔ **🧪 ساخت آزمون جدید** ← ویزارد ۵ مرحله‌ای:

1. **عنوان** — مثل: «آزمون جامع درس ۱ و ۲ Vision 2»
2. **پایه** — دهم / یازدهم / دوازدهم
3. **درس‌ها** — چنددوره‌ای؛ خالی بگذاری = همهٔ درس‌ها
4. **زمان** — بدون زمان / ۱۰ / ۲۰ / ۳۰ / ۴۵ / ۶۰ دقیقه
5. **شیوهٔ سؤال‌سازی** 👇

### ✍️ دستی
سؤال → چهار گزینه → گزینهٔ درست → توضیح (اختیاری) → سؤال بعدی → 🏁 پایان آزمون‌سازی

### 📥 ایمپورت فایل
فایل CSV / XLSX / JSON یا **لینک گوگل‌شیت** بفرست. ستون‌ها:

```
question, option1, option2, option3, option4, correct, explanation
```
> correct = شمارهٔ گزینهٔ درست (۱ تا ۴)

💡 **گوگل‌شیت:** Share ← Anyone with the link ← لینک را بده به ربات؛ خودش CSV می‌گیرد 📡

### 📋 مدیریت آزمون‌ها
فعال/غیرفعال، مشاهدهٔ آمار شرکت، حذف و **انتشار نتایج** از همین‌جاست.

---

## 🃏 فلش‌کارت

- **➕ افزودن دستی:** ویزارد کامل — پایه ← درس ← دسته ← روی کارت ← پشت کارت ← مثال ← نکته
- **📥 ایمپورت:** همان فایل‌سی‌وی با ستون‌های `front, back, example, tip`
- **آمار کارت‌ها:** جدول تعداد هر پایه/درس/دسته در منوی فلش‌کارت پنل

---

## 📊 انتشار نتایج (مهم‌ترین بخش!)

قانون ربات: **هیچ نمره/ترازی قبل از تأیید تو دیده نمی‌شود.** 🔒

1. «📊 مدیریت نتایج» ← آزمون موردنظر
2. آمار زنده را می‌بینی: تعداد شرکت‌کننده، میانگین، بالاترین/پایین‌ترین درصد
3. «✅ بله، منتشر کن»
4. ربات:
   - تراز و رتبهٔ همه را حساب می‌کند
   - به هر دانش‌آموز **کارنامهٔ شخصی** می‌فرستد 📩
   - لیدربورد آن آزمون را باز می‌کند 🏆

---

## 👥 مدیریت کاربران

«👥 مدیریت کاربران» ← **اسم یا آیدی عددی** را بفرست 🔍
روی کاربر می‌توانی:
- **🔒 مسدود / 🔓 رفع مسدودی**
- **🛡 ادمین‌کن / ➖ حذف ادمین** (فقط صاحب)
- آمار کاملش را ببینی (کارت‌ها، آزمون‌ها، امتیاز، آخرین فعالیت)

---

## 📢 پیام همگانی

1. «📢 پیام همگانی»
2. متنت را بنویس ← **پیش‌نمایش** می‌بینی
3. ✅ تأیید ← به همهٔ کاربران فعال ارسال می‌شود

گزارش موفق/ناموفق هم آخرش می‌آید (ناموفق = کاربر اصلا بلاک کرده).

---

## ✏️ ویرایش متن‌ها

«✏️ ویرایش متن‌ها» ← سه متن کلیدی ربات:
- **ℹ️ درباره ما**
- **📬 تماس با ما**
- **📖 راهنما**

هر متنی که بفرستی جایگزین می‌شود — HTML سبک تلگرام هم پشتیبانی می‌شود (`<b>`, `<i>`, `<a href>`).

---

## 🥇 بهترین تمرین‌ها

- آزمون‌های جدید را **هفته‌ای** منتشر کن تا لیدربورد زنده بماند 🏆
- قبل از انتشار نتایج، آمار را نگاه کن — اگر میانگین درصد خیلی بالاست، آزمون آسان بوده است 😉
- پیام همگانی را برای اطلاع‌رسانی آزمون جدید استفاده کن، نه هر روز (اسپم نشو 🙏)
- هرازگاهی دیتابیس را بک‌آپ کن: `cp data/ghayoomi.db data/backups/$(date +%F).db`
